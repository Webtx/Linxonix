## About

**Linxonix** is a lightweight web application that allows users to browse and customize small avatars. The project focuses on a clean, responsive interface and easy integration with static assets.

---

## Features

- Interactive avatar previews
- Responsive design for desktop and mobile
- Easy-to-edit avatar assets
- Clean codebase with ESLint and Stylelint configurations
